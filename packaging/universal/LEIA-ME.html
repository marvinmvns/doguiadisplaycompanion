DoguIA Companion

Extrair. Instalar.
Conectar.

Um pacote para Windows, macOS e Linux. Python já está incluído. Não é necessário instalar bibliotecas ou manter uma conexão com a internet durante a instalação.

1. Extraia o ZIP inteiro

Mantenha a pasta pacotes junto dos arquivos “Instalar DoguIA”. Não abra o instalador de dentro do ZIP.

2. Abra o instalador

Windows 10/11 x64: dê dois cliques em Instalar-DoguIA.cmd.

macOS Intel ou Apple Silicon: abra Instalar-DoguIA.command. O sistema pode pedir confirmação para abrir um arquivo baixado; o pacote nativo não tem assinatura Apple. O instalador do macOS solicita a senha de administrador.

Linux x64: abra um terminal nesta pasta e execute sh Instalar-DoguIA.command. Instala só para seu usuário, sem sudo. Requer uma distribuição com glibc compatível com o binário; Alpine/musl e Linux ARM não estão incluídos.

O sistema e a arquitetura são detectados automaticamente, e o pacote é conferido antes de executar.

3. Configure seu Display

O assistente abre após a instalação. Conecte computador e Display à mesma Wi-Fi, informe o IP e siga as etapas. Depois, abra “Configurar DoguIA Usage” no menu de aplicativos.

Atualizar ou remover

Para atualizar, repita a instalação com o novo ZIP. Seus ajustes ficam preservados. Windows: use Aplicativos instalados. macOS: abra “Desinstalar DoguIA Usage” em Aplicativos/DoguIA Usage. Linux: execute o uninstall.sh guardado em ~/.local/share/doguia-usage (ou na pasta XDG_DATA_HOME correspondente).

Se o pacote não passar na conferência, baixe novamente. Essa conferência detecta arquivo incompleto ou alterado; obtenha o ZIP pelos canais oficiais DoguIA.
